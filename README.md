# Thom Polynomial Portal

The new version of the [Thom Polynomial Portal](https://tpp.web.unc.edu/), migrated from WordPress in November 2026
and still under construction. Published at **https://rimanyi.github.io/tpp-sandbox/**.

## Where things are

| Folder | What it holds | Edit it? |
|---|---|---|
| `data/catalog/contact.yaml` | the list of contact singularities with their invariants | yes |
| `data/catalog/multi.yaml`, `lac.txt`, `old-urls.yaml` | extra text for multi-singularities, LAC splittings, old URL map | yes |
| `data/contact/<NAME>/` | data files of a singularity, e.g. `data/contact/A2/tp_l2.txt` | yes |
| `data/multi/<NAME>/` | data files of a multi-singularity, e.g. `data/multi/2A0+A2/`, `data/multi/EMPTY/` | yes |
| `data/catalog/thom-boardman.yaml`, `data/thom-boardman/<NAME>/` | the Thom–Boardman classes that have a page, and their data files, e.g. `data/thom-boardman/Sigma2/` | yes |
| `content/` | the hand-written pages (Markdown), styles and scripts | yes |
| `files/` | PDFs, pictures and other downloads (empty for now; they are still linked from the old site) | yes |
| `scripts/` | the program that turns the above into web pages (`build_site.py`), and `import_ktp_dataset.py`, which turns the authors' K-theory data set into data files | rarely |
| `migration/` | the one-time conversion from WordPress, and its report | no |
| `.github/workflows/` | tells GitHub to rebuild the site after every push | no |

## Data files

One file per singularity × kind of data × relative dimension. Lines starting with `#` describe the contents
(source, codimension, degree, where it came from); the rest is Maple input:

```
# title: Thom polynomial of A2, relative dimension l=2
# kind: tp
# l: 2
# codimension: 6
...
Tp_A2_l2_monomial := 2*c[1]*c[5] +c[2]*c[4] +c[3]^2 +4*c[6]:
Tp_A2_l2_schur := 8*s[[6]] +s[[3,3]] +2*s[[4,2]] +4*s[[5,1]]:
```

To add a polynomial, add a file in the same format; the singularity page, the tables and the state-of-knowledge page
pick it up automatically.

Kinds of files in a singularity's folder:

| File | Contents |
|---|---|
| `tp_l2.txt`, `series.txt` | Thom polynomial for one `l`; Thom series (all `l`) |
| `ssm_l2.txt` | SSM-Thom polynomial (of the singularity locus itself), a series in `t` |
| `ktp_l2.txt` | K-theoretic Thom polynomial, push-forward version, in Grothendieck polynomials `gr[[lambda]]` |
| `ktp_ms0_l2.txt` | K-theoretic Thom polynomial, MS0 version (only where it differs from the push-forward version) |
| `ms_closure_l2.txt`, `ms_orbit_l2.txt` | motivic Segre Thom polynomial of the closure / of the singularity locus itself, a series in `z` |
| `multi_target_ssm_l2.txt`, `multi_source_ssm_l1.txt` | the singularity as a one-point multi-singularity |

The K-theory files were generated by `python scripts/import_ktp_dataset.py PATH_TO_THE_DATA_SET` from the authors' data set
of 2026-11-25, which is not part of this repository. Their `source:` line is the credit line shown on the site.

## Building the site on your own computer (optional)

```
pip install -r requirements.txt
python scripts/build_site.py
mkdocs serve
```
